# GodotPartyDefault · 心理博弈

2–8 人在线单循环配对，每对只相遇一次。默认每轮 30 秒，可在大厅设置 5–120 秒。选择合作/背叛后立即锁定；收益为 3/3、0/5、5/0、1/1。超时默认背叛，断线超时单独记录，轮空 0 分。总分降序，同分并列，整局结束后公开每对选择和收益。

从「原版小游戏派对」的 originals 池启动。房主维护秘密状态，每个客户端只收到自己的选择状态和允许看到的结果；观战者收到公开快照。即使房主不参赛也承担协调。

使用 PartyVoice 的真实 group 路由：每轮只连通搭档，双方都选定后关闭这一对；下一轮前先关闭全部。路由 API 返回失败则取消本局，不能假装 mock 成功。API 确认代表房主已接受转发规则，不代表远端设备听感已验收。

麦克风默认关闭，玩家主动点击按钮开启，并且必须已经在系统设置授权麦克风。无需麦克风也能提交选择。离开作用域关闭端点、移除本局音频总线。真实设备、弱网和多人语音听感仍需人工验证。

只支持 standard 普通局。使用 temp_game/PsychologicalPartyGame 的排程、收益和权威状态机，替换 demo 本地视角切换和 mock_voice_router；不读取原型测试身份或虚构网络保密。
