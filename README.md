# PsychologicalPartyGame · 心理博弈派对模块

独立 Godot 4.7 项目。打开 `project.godot`，按 F6/F5 运行本地调试场景。

**实现边界：这是权威规则模块 + 集成接口 + 单机多玩家视角调试工具。尚未实现真实联网、语音传输、线上身份认证或网络级保密。切换本地视角不是安全隔离。** 不依赖、修改或嵌入其他卡牌/UI 项目；未来可由统一 3D 派对框架替换 demo 表现层。

## 已实现规则

- 2–8 人，全员单循环配对。偶数 N 为 N−1 轮，奇数 N 为 N 轮且每轮一人轮空。每对只遇见一次，每轮不同配对同时进行。
- 每轮只为当前搭档开放路由；双方秘密选择“合作 / 背叛”，提交即锁定。双方都提交后立刻请求关闭这一对语音。
- 选择和通话共用时限，默认 30 秒（可配置 >0 至 3600 秒）。仅路由开启获确认后开始计时。超时未选择一律背叛，记录 `timeout`；断线不提前选择，到期记录 `disconnected_timeout`。
- 默认收益：合作/合作 3/3，合作/背叛 0/5，背叛/合作 5/0，背叛/背叛 1/1。配置整局冻结并验证 T > R > P > S。轮空 0 分；总分排名，同分同名次。
- 默认整局完成后统一揭晓；可选“每对完成后仅双方揭晓”。公开快照中途始终不含选择、收益或排行榜；自己的私有快照只含自己的已选项和有权看到的结果。最终所有人可见全局结果。
- 所有配对完成并确认关闭后，必须完成 `close_all` 屏障才开启下一轮。最后也必须关闭成功才进入最终揭晓。
- 路由失败或 5 秒未确认时暂停玩法，禁止开新轮；重试成功后继续。实际音频能否立即停止由接入的供应商执行能力决定，本模块不假装能保证第三方故障时的音频已关闭。
- 支持取消、重启、重复/迟到/错误身份请求拒绝、旧轮及旧局消息拒绝、旧路由确认丢弃。

## 目录

- `core/rules.gd`：纯排程、收益与配置校验。
- `core/session.gd`：权威状态机、秘密选择、时限、结算、授权快照、路由确认屏障。
- `adapters/host_adapter.gd`：单调主机时间、认证玩家映射接缝、派对框架入口。
- `adapters/mock_voice_router.gd`：仅验证控制协议的语音 mock，不调用麦克风。
- `demo/main.tscn`：可直接运行的场景化调试界面。
- `tests/run_tests.gd`：无外部依赖的自动化测试。

参见 [集成 API](docs/API.md) 与 [运行及测试](docs/TESTING.md)。
